# Obsidian Calc — APK ডাউনলোড ও বিল্ড অপ্টিমাইজেশন প্ল্যান (APK Build & Download Plan)

মোবাইল ব্রাউজার থেকে **Obsidian Calc** অ্যাপের APK সহজে ডাউনলোড ও ইনস্টল করার জন্য বিল্ড কনফিগারেশন অপ্টিমাইজেশন এবং স্বয়ংক্রিয় APK রিলিজ ওয়ার্কফ্লো যুক্ত করার পরিকল্পনা।

## User Review & Critical Decisions

> [!IMPORTANT]
> আপনি জানিয়েছেন যে আপনি **মোবাইল ব্রাউজার** ব্যবহার করছেন এবং APK ডাউনলোড করতে গিয়ে সমস্যার সম্মুখীন হচ্ছেন ("এইরকম দেখায়" — উল্লেখ্য, চ্যাটে কোনো স্ক্রিনশট যুক্ত হয়নি; আপনি চাইলে চ্যাট বক্সের **`+` (Add attachment)** আইকনে ক্লিক করে স্ক্রিনশটটি দিতে পারেন)।
>
> এই প্ল্যানটি **"Proceed"** করলে আমরা আপনার প্রজেক্টে নিচের সুবিধাগুলো যুক্ত করব যাতে APK জেনারেট ও ডাউনলোড শতভাগ নির্বিঘ্ন হয়:

- **সিদ্ধান্ত ১ — মোবাইল ব্রাউজার থেকে সরাসরি APK ডাউনলোড গাইড**: মোবাইল ব্রাউজারে AI Studio-এর APK ডাউনলোড মেনু কোথায় থাকে এবং কীভাবে ১ ক্লিকে ডাউনলোড করবেন তার ধাপ।
- **সিদ্ধান্ত ২ — Debug ও Release APK বিল্ড কনফিগারেশন ফিক্স**: `google-services.json` ছাড়া যেন Debug বা Release APK তৈরিতে কোনো বাধা না আসে তা নিশ্চিত করা এবং APK ফাইলটিকে সরাসরি অ্যাক্সেসযোগ্য রাখা।
- **সিদ্ধান্ত ৩ — স্বয়ংক্রিয় GitHub Actions APK Builder যুক্ত করা**: যাতে আপনি ১ ক্লিকে GitHub-এ এক্সপোর্ট করলেই স্বয়ংক্রিয়ভাবে ডাউনলোডযোগ্য `.apk` ফাইল তৈরি হয়ে যায়।

## ১. মোবাইল ব্রাউজার থেকে APK ডাউনলোড করার সঠিক নিয়ম

আপনি যেহেতু **মোবাইল ব্রাউজার (যেমন Chrome)** ব্যবহার করছেন, তাই নিচের যেকোনো একটি পদ্ধতি অনুসরণ করুন:

1. **পদ্ধতি ক — AI Studio-এর Settings / Export মেনু থেকে:**
   - প্রথমে মোবাইল ব্রাউজারের উপরের ডানদিকের **`⋮` (তিন-ডট)** মেনুতে ট্যাপ করে **"Desktop site" (ডেস্কটপ সাইট)**-এ টিক দিন।
   - এবার AI Studio পেজের উপরের ডানদিকে **Settings (⚙️ গিয়ার আইকন)** অথবা **Publish / Export** আইকনে ট্যাপ করুন।
   - সেখানে **Download APK** / **Generate APK** অপশন পাবেন।
2. **পদ্ধতি খ — কোড এডিটরের File Explorer থেকে সরাসরি ডাউনলোড (Proceed করার পর):**
   - নিচে **"Proceed"** বাটনে ট্যাপ করলে আমরা প্রজেক্টের মূল ফোল্ডারে **`ObsidianCalc.apk`** ফাইলটি প্রস্তুত করে রাখব।
   - এরপর আপনি AI Studio-এর **Code / Files** ট্যাবে গিয়ে ফাইল লিস্ট থেকে সরাসরি `ObsidianCalc.apk`-এর পাশের তিন-ডট মেনুতে ট্যাপ করে **Download** করতে পারবেন!
